FILOSOFI & MASALAH BISNIS

Mengapa ProMaP? Solusi Eksekusi Rencana Strategis

⚠️ Masalah Klasik Eksekusi di Perusahaan

✕ Rencana Berhenti di Notula: Program kerja hanya hangat saat rapat, minim tindak lanjut konkret harian.
✕ Spreadsheet Berceceran: Laporan terpencar di berbagai file Excel dan chat grup tanpa kendali versi.
✕ Klaim Selesai Tanpa Bukti: Progres sering dicatat 100% tanpa adanya verifikasi berkas hasil kerja riil.
✕ Overdue Terabaikan: Keterlambatan batas waktu baru disadari saat evaluasi akhir kuartal.

✨ Solusi Terpadu ProMaP V2.4

✓ Single Source of Truth: Semua divisi (Marketing, Ops, HR, Finance) bekerja di satu workspace terpadu.
✓ Akuntabilitas Berbasis Bukti: Action Plan wajib melampirkan evidence nyata sebelum dapat disetujui Manager.
✓ Siklus 8 Status Ketat: Mencegah manipulasi status progres dan memastikan kontrol kualitas pekerjaan.
✓ Deteksi Keterlambatan Otomatis: Cron sistem menandai OVERDUE setiap 00:01 WIB secara adil & objektif.

Hierarki Kerja: Dari Inisiatif Besar ke Aksi Lapangan

Struktur fleksibel yang berlaku untuk seluruh divisi (Marketing, Operasional, HR, Keuangan, dsb).

LEVEL 1
PROJECT (INISIATIF)
Payung Program Kerja

Wadah inisiatif strategis seperti 'Kampanye Q3', 'Audit SOP Gudang', 'Pembaruan Fasilitas'.

LEVEL 2
TASK (SASARAN)
Paket Deliverable

Paket deliverable terdelegasi di bawah Project dengan PIC penanggung jawab dan deadline spesifik.

LEVEL 3
ACTION PLAN
Aksi Eksekusi PIC

Langkah operasional harian PIC dengan siklus 8 status ketat dan kewajiban mengunggah bukti hasil.

LEVEL 4
CHECKLIST
Milestone Detail

Daftar verifikasi mikro di dalam Action Plan yang dicentang bertahap untuk menghitung persentase.

💡 Proposal (Bottom-Up Innovation)

Pintu masuk inisiatif dari staf lapangan ke Manager. Jika disetujui, langsung bertransformasi menjadi Action Plan resmi.

📌 Personal Task (To-Do Pribadi)

Catatan tugas mandiri PIC yang tidak memengaruhi indikator capaian atau agregasi KPI tim divisi.

ALUR PENGGUNAAN UTAMA

Alur 1: Inovasi Usulan dari Bawah (Proposals)

Memberi ruang bagi staf pelaksana untuk mengusulkan ide strategis dengan mekanisme evaluasi formal.

1
Staf Ajukan Draft

PIC menyusun usulan di menu Proposals. Mengisi latar belakang, proyeksi dampak, kebutuhan anggaran, & tanggal sasaran.

2
Masuk ke Manager

Status berubah menjadi SUBMITTED. Usulan otomatis muncul di panel Action Required dashboard Manager divisi.

3
Review & Keputusan

Manager membaca detail proposal melalui Drawer samping. Jika ditolak, Manager wajib menyertakan catatan alasan.

4
Otomasi Action Plan

Jika disetujui (APPROVED), sistem otomatis mengubah proposal menjadi Action Plan resmi di bawah Project terkait.

STANDAR OPERASIONAL EKSEKUSI

Alur 2: Siklus 8 Status Eksekusi Action Plan

1. NOT_STARTED

Baru dibuat oleh Manager atau dikonversi dari proposal; menunggu eksekusi PIC.

2. IN_PROGRESS

PIC mengklik tombol mulai; pengerjaan harian sedang berlangsung secara aktif.

3. PENDING_APPROVAL

PIC telah mengunggah bukti dan mengajukan review ke Manager divisi.

4. EVIDENCE_REQUIRED

Manager meminta bukti lampiran tambahan karena bukti awal belum memadai.

5. APPROVED

Hasil kerja dan bukti terverifikasi valid dan disetujui penuh oleh Manager.

6. COMPLETE

Tahapan tuntas sempurna dan tercatat dalam perhitungan capaian KPI divisi.

7. REJECTED

Ditolak dengan catatan perbaikan; status kembali ke In Progress untuk direvisi.

8. OVERDUE

Ditandai otomatis oleh Vercel Cron tiap pukul 00:01 WIB jika lewat tenggat.
